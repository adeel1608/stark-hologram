# Dependencies and asset licensing

Direct dependency metadata was inspected from the installed packages and lockfile during the v0.2 modernization.

| Package                                     | Role                             | Installed baseline | License                   |
| ------------------------------------------- | -------------------------------- | ------------------ | ------------------------- |
| `three`                                     | 3D rendering and GLTF loader     | 0.186.0            | MIT                       |
| `@mediapipe/tasks-vision`                   | Hand Landmarker browser runtime  | 1.0.1              | Apache-2.0                |
| `vite`                                      | development and production build | 8.3.0              | MIT                       |
| `typescript`                                | static typing                    | 5.9.3              | Apache-2.0                |
| `eslint`, `@eslint/js`, `typescript-eslint` | linting                          | 10.x / 8.70.0      | MIT/BSD-2-Clause packages |
| `prettier`                                  | formatting                       | 3.9.6              | MIT                       |
| `vitest`, `@vitest/coverage-v8`             | tests and coverage               | 5.0.0              | MIT                       |

The lockfile is committed for reproducible installs and contains registry integrity hashes and license metadata. `npm audit` reported no known vulnerabilities at the time of modernization; that is a point-in-time check, not a guarantee.

No external robot, Marvel, film, audio, image, or font asset is bundled. The reference robot and interface geometry are generated by project code. Audio cues are synthesized with the Web Audio API. The MediaPipe model is fetched from the official Google-hosted model URL at runtime and is not redistributed in this repository.

Contributors must document the exact source and redistribution license before adding any third-party GLB, image, audio, dataset, or recorded landmark session.
